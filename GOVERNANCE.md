# Governance: Aire

Aire is in its early stages. To ensure clarity and stability, this document defines how decisions are made and how stewardship will evolve.

---

## Current Model: BDFL
- **Benevolent Dictator for Life (BDFL):** @mr-kelley (project founder)
- Responsibilities:
  - Final decision-maker on design and scope
  - Maintains release cadence and roadmap
  - Oversees code quality and contributor onboarding
- Input from the community is strongly encouraged via Issues and Discussions.

---

## Evolution Plan
Governance will evolve as the project grows:

- **Pre-v1.0:**
  - BDFL model continues
  - PRs accepted selectively (bugfixes, small features)
  - Formal RFC process begins at v0.3

- **Post-v1.0:**
  - Transition to a **core maintainers team**
  - Decision-making by consensus with fallback to BDFL
  - Governance doc revised and ratified by maintainers

---

## Values
- **Transparency:** All major decisions discussed openly.
- **Stewardship:** Features must support long-term stability and clarity.
- **Respect:** Collaboration follows the Contributor Covenant Code of Conduct.
